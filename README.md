# Train-the-Trainer Kit for Biobank Assessment

Website: https://swissbiobanking.github.io/Train-the-Trainer_Kit/

Built with [Zensical](https://zensical.org/). Pages are Markdown files in `docs/`; the menu and site settings are in `zensical.toml`.

## Edit the content

Edit the `.md` files in `docs/` (directly on GitHub is fine). Every push to `main` rebuilds and publishes the site automatically.

## Preview locally

```bash
pip install zensical
zensical serve
```

Then open http://localhost:8000.
